# Text+ Utilities

DVR Smart Edit provides essential utilities for `Text+`.

---

## Generate Text+
Generate Text+ clips from subtitle track or SRT file.

1. **Open Smart Edit Menu**:
    - Open menu from `Workspace > Scripts > SmartEdit > Menu`.
    - Go to `Text+` tab.

2. **Generate**:
    - Set parameters.
    - Click `Generate`.

---

## Copy Text+ Style

1. **Select Style**:
    - In Media Pool, select the **Text+** clip with desired style.

2. **Open Text+ Utilities Menu**:
    - In timeline, select the **Text+** clip to apply style to.
    - In **Inspector**, right click text edit control and choose `SmartEdit Text+ Menu`

3. **Apply Style**:
    - Under `Text+ Utilities Menu > Styling > Copy Style from Media Pool`, select:
    - `to This Clip`: Apply style to the selected clip in timeline.
    - `to This Track`: Apply style to every Text+ clips in the track where the selected clip belong to.
    - `to All`: Apply style to all Text+ clips in the timeline.
